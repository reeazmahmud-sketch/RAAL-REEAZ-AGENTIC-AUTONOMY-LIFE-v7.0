# Roadmap (phased)

## Phase 1 — Foundation hardening (current)
- Keep planner deterministic and easy to reason about.
- Expand docs and clarify extension contracts.
- Increase unit tests around edge cases and config bounds.

## Phase 2 — Internal policy layer
- Add explicit policy checks on generated plan steps.
- Add structured plan validation results.
- Keep execution simulation-only.

## Phase 3 — Observability maturity
- Improve audit event schema consistency.
- Add richer execution summaries and traceability helpers.
- Document compatibility and migration expectations.

## Non-goal for current roadmap
Enabling unsupervised real-world autonomous actions is out of scope for this repository stage.
